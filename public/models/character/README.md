Coloque frog.glb neste diretório. Recarregue a página para substituir o placeholder.
Use um GLB autocontido, em pé, com eixo Y para cima e frente apontando para +Z.
Para modelos cuja frente seja -Z, configure facingRotation: Math.PI em createApp.js.
A altura é normalizada para 1,8 unidades, com os pés no chão e o corpo centralizado.
Nenhum modelo definitivo é incluído nesta etapa.
