Reservado para arquivos de animações futuros. Nenhuma animação é inventada ou baixada.
Clips incorporados em frog.glb são registrados automaticamente pelo nome original.
Nomes reconhecidos: idle, passinho, giro, moonwalk, pose-sigma, dab, breakdance.
Clips externos deverão ser carregados e registrados com character.registerAnimation(nome, clip).
Os clips precisam usar os mesmos nomes de ossos e um rig compatível com o personagem.
